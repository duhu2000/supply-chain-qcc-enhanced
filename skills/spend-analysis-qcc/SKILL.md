## MCP 配置要求

**⚠️ 重要：中国供应商丰富需要企查查MCP**

```bash
# ~/.claude/.mcp.json
{
  "mcpServers": {
    "qcc-company": { "url": "https://agent.qcc.com/mcp/company/stream" },
    "qcc-risk": { "url": "https://agent.qcc.com/mcp/risk/stream" }
  }
}
```

## QCC 增强功能 — 中国供应商情报

### 整合分析供应商丰富

支出分析中的中国供应商**自动丰富**企查查数据：

1. **供应商登记状态（qcc-company）**
   - 工商状态验证
   - 注册资本评估
   - 经营范围匹配

2. **风险信号覆盖（qcc-risk）**
   - 经营异常标记
   - 行政处罚历史
   - 涉诉情况

3. **经营规模指标**
   - 员工数量趋势
   - 分支机构网络
   - 历史增长指标

## 通用规则

- 绝不接受包含虚构财务数据的供应商风险评估
- **中国供应商：整合决策始终使用企查查数据**
- 始终包含具体建议行动和截止日期
